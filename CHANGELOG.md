# Changelog

## Non rilasciato

- Aggiunta la gestione delle sessioni composte da giri di cinque mani.
- Dopo la quinta mano l'host può iniziare un nuovo giro o concludere la sessione.
- Le sessioni concluse non accettano più modifiche.
- Il capotto è ora valido sia nella vittoria sia nella sconfitta del chiamante, incluso Carichi.
- Aggiunta una pipeline GitHub Actions per verifiche e migrazioni Supabase.
- Documentato il flusso di sviluppo con branch, pull request e migrazioni versionate.
